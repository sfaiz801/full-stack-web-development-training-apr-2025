Module 06

Custom Bootstrap Theming & SCSS Overrides

Overriding default Bootstrap Sass maps, color palettes, border radii, and variables to build unique brand identities.

1. Live Themed Components

All buttons, badges, borders, and surfaces automatically inherit our custom brand tokens:

Custom Border Radius: 0.75rem rounded
Theming Benefit: Change one SCSS/CSS variable and every Bootstrap component in the entire project updates synchronously!

2. SCSS Variable Override Pattern

Declared in _custom_theme_variables.scss before importing Bootstrap:

// 1. Override default theme colors
$primary:   #38bdf8 !default;
$secondary: #818cf8 !default;
$body-bg:   #090d16 !default;

// 2. Override component geometry
$border-radius:    0.75rem !default;
$border-radius-lg: 1.00rem !default;

// 3. Enable advanced features
$enable-gradients: true !default;
$enable-shadows:   true !default;

// 4. Import Bootstrap
@import "bootstrap/scss/bootstrap";
