SCSS Design Tokens & Mixins

Modular BEM

This card was styled completely using our modular SCSS partial system. It uses an @extend %elevation-card placeholder for spring hover physics, @include glass-effect() mixin for frosted backdrop blur, and mathematical rem() functions for responsive sizing.

SCSS Partial Structure

7-1 Pattern

Modular Sass files separated into maintainable single-responsibility partials:

scss/
├── _variables.scss    // $primary-color, $bg-dark, $font-main
├── _functions.scss    // @function rem($pixels) { @return ... }
├── _mixins.scss       // @mixin glass-effect(), @mixin flex-center()
├── _placeholders.scss // %elevation-card, %interactive-button
├── _components.scss   // .course-card { &__header { ... } }
└── main.scss          // Master entry compiling into css/main.css
