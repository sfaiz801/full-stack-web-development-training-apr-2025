# 🅱️ Bootstrap 5 & SCSS: Student Learning Journey

A comprehensive structured curriculum mapping each student's journey from Bootstrap fundamentals, responsive containers, 12-column grid systems, and breakpoints to essential components (navbars, cards, modals, accordions, and validated forms) and modern SCSS architecture (variables, nesting, mixins, functions, inheritance, partials, and custom theme overrides).

---

## 🗺️ Curriculum Architecture

```
Boostrap/Structured_Modules/
├── 01_Bootstrap_Grid_and_Breakpoints/       # 12-column grid, breakpoints (sm, md, lg, xl, xxl), containers, gutters, offsets
├── 02_Bootstrap_Components_and_Navigation/  # Navbar, toggler, nav pills, breadcrumbs, pagination, badges, dismissible alerts
├── 03_Bootstrap_Cards_and_Modals/           # Card decks (row-cols), headers/footers, centered modals, static backdrops
├── 04_Bootstrap_Forms_and_Utilities/        # Floating labels, input groups, switches, was-validated states, flex utilities
├── 05_SCSS_Architecture_and_Partials/       # Variables ($), nesting (&), mixins (@mixin), functions (@function), inheritance (@extend)
└── 06_Custom_Bootstrap_Theming/             # Sass variable overrides ($primary, $border-radius), custom theme tokens
```
