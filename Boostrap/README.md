This module maps each student's journey from Bootstrap fundamentals, 12-column grid systems, containers, and breakpoints to mastering components (navbars, cards, modals, forms, and utilities) and advanced SCSS architecture (variables, nesting, mixins, functions, inheritance, partials, and custom theme overrides).

By completing these practical tasks, you will learn:
- How to structure layouts using the **Bootstrap Grid System** (Containers, Rows, Columns).
- Leveraging **Bootstrap Components** (Navbars, Cards, Modals, Carousels, Accordions).
- Using **Utility Classes** for spacing, sizing, colors, and typography without writing custom CSS.
- Implementing **Form Controls** with floating labels and custom validation states.
- Building **Responsive Interfaces** that adapt beautifully to mobile, tablet, and desktop screens.

## 📂 Practice Tasks

An interactive hub linking to all practice tasks is available at [`index.html`](file:///d:/full-stack-web-development-training-apr-2024/Boostrap/index.html).

### 1. Admin Dashboard Layout (`/01_admin_dashboard_layout`)
A complex UI layout featuring a fixed sidebar, top navigation bar, statistical data cards, and a responsive data table.
**Key Concepts**: Flexbox utilities, responsive grid, icons, tables.

### 2. E-Commerce Product Page (`/02_ecommerce_product_page`)
A detailed product view interface complete with an image carousel, thumbnail synchronization, pricing displays, and toast notifications for user actions.
**Key Concepts**: Carousel, accordions, toast notifications, badges, form checks.

### 3. Pricing Plans Section (`/03_pricing_plans_section`)
A clean, scalable, three-tier pricing table section highlighting a popular plan.
**Key Concepts**: Cards, hover effects, flexbox alignment, typography utilities.

### 4. Interactive Login Form (`/04_interactive_login_form`)
A modern authentication page with split-screen layout, custom form validation, and a modal popup for password recovery.
**Key Concepts**: Floating labels, form validation feedback, modals, shadows.

### 5. Portfolio Landing Page (`/05_portfolio_landing_page`)
A comprehensive single-page portfolio website showcasing smooth scrolling, fixed navigation, progress bars, and a project gallery.
**Key Concepts**: Scrollspy, fixed-top navbar, progress bars, hero sections.

## 🚀 How to Run

These are static HTML files utilizing the Bootstrap CDN. You do not need Node.js or a build step to run them.
Simply open the [`index.html`](file:///d:/full-stack-web-development-training-apr-2024/Boostrap/index.html) file located in this directory directly in your preferred web browser to view and navigate through the projects.
