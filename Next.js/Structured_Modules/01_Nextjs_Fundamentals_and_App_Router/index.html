React Server Components (RSC) vs Client Components

Server Component (Default) SERVER-ONLY

Renders directly on the server. Zero JavaScript sent to the client bundle. Direct secure access to databases, filesystem, and private API keys.

// app/page.jsx (Server Component)
export default async function Page() {
  const data = await db.query();
  return <h1>Hello Server!</h1>;
}
Client Component 'use client'

Opt-in for browser interactivity (state, effects, event listeners like onClick, browser APIs).

'use client';
import { useState } from 'react';
export default function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick=...>{count}</button>;
}

Next.js App Router File Convention

📁 app/
├── 📄 layout.jsx       // Persistent Root Layout wrapping all pages
├── 📄 page.jsx         // Unique UI for route / (Server Component)
├── 📄 loading.jsx      // Instant loading skeleton via React Suspense
├── 📄 not-found.jsx    // Custom 404 UI
└── 📁 dashboard/
    ├── 📄 layout.jsx   // Nested dashboard layout (sidebar + header)
    └── 📄 page.jsx     // Route: /dashboard
