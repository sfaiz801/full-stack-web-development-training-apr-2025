# Cloud & Authentication (Firebase)

This section focuses on **Firebase Authentication** for handling user signup, login, and secure user sessions in full-stack web applications.

## 🎯 What is Covered

* **User Authentication**: Implementing email/password signup and login with Firebase.
* **Social Authentication**: Google sign-in using Firebase Auth SDK.
* **Client & Backend Integration**: 
  - How the frontend (React / Next.js) signs in the user and receives an `idToken`.
  - How the backend (FastAPI) receives this token in the `Authorization: Bearer <token>` header to authenticate user requests.
