## 📂 Additional Practice Exercises Index

### 1. 🟢 Basics & Control Flow
* `hello.c`, `hellow.c` - Basic output and syntax
* `alphabat.c`, `alphabatdowhile.c` - Alphabet generation with while and do-while loops
* `loop.c`, `forloop.c` - Loop control constructs
* `cube.c`, `cuben.c` - Mathematical cube calculations
* `fac.c` - Factorial computation

### 2. 🟡 Conditionals & Decision Making
* `04election.c` - Voting eligibility checker
* `even.c`, `evenodd.c` - Even/Odd number checks
* `evenoddadd.c`, `evenoddsum.c` - Conditional accumulation
* `schoolresult.c` - Grade calculation and mark sheet generation

### 3. 🔵 Arrays & Data Manipulation
* `numberarray.c` - Array declaration, traversal and printing
* `evennumberarray.c` - Filtering and storing even numbers in arrays
* `arraycopypaste.c` - Copying elements from one array to another
* `arrayfunctionality.c` - Common array utility operations
* `assendingorder.c` - Bubble/Insertion sort in ascending order
* `dublicate.c`, `solve.c` - Detecting and counting duplicate elements in an array
* `reverse.c` - Array inversion and string reversal

### 4. 🟣 Functions & Modular Programs
* `function.c`, `function2.c` - Defining user functions, parameter passing and return types
* `calculation.c`, `calculator.c`, `calculator2.c` - Multi-operation console calculators
* `sum.c`, `Task-17_sum function/` - Summation utilities with functions
